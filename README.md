# TerminalAdventure

Бесконечное терминальное приключение на C++17. Проходите этапы с растущей сложностью, сражайтесь с противниками, используйте зелья и распоряжайтесь ограниченным запасом пропусков.

**Стек:** C++17 · ncurses · CMake · Docker · Linux

## Игровой процесс

На каждом этапе встречается противник, зелье или пустое пространство. По мере прохождения враги становятся сильнее, а действие зелий — заметнее.

- **Противники:** слабые, средние и сильные, с разными значениями здоровья, урона и брони.
- **Зелья:** полезные восстанавливают характеристики, вредные снижают их.
- **Пропуски:** позволяют обойти встречу, пока есть запас пропусков.
- **Результат:** задача — пройти как можно больше этапов; после завершения можно начать новую игру.

Интерфейс показывает здоровье, силу, броню, текущий этап, счёт и доступные команды.

## Быстрый запуск через Docker

Установите Docker, затем соберите образ и запустите игру в интерактивном терминале:

```bash
git clone https://github.com/ST3PAN0V/TerminalAdventure.git
cd TerminalAdventure
docker build -t terminal-adventure .
docker run --rm -it --entrypoint /app/build/TerminalAdventure terminal-adventure
```

Используйте достаточно большое окно терминала: текущий интерфейс имеет фиксированную компоновку.

## Сборка из исходников

Понадобятся:

- Linux.
- Компилятор с поддержкой C++17.
- CMake 3.11 или новее и совместимый инструмент сборки.
- Библиотека ncurses и её заголовочные файлы для разработки.

Из корня репозитория выполните:

```bash
mkdir -p build
cd build
cmake ..
cmake --build .
./TerminalAdventure
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `a` | Атаковать противника на текущем этапе |
| `u` | Использовать зелье на текущем этапе |
| `n` | Перейти дальше, когда это разрешено |
| `s` | Пропустить этап, если есть доступный пропуск |
| `q` | Выйти с экрана завершения игры |
| Любая другая клавиша на экране завершения | Начать новую игру |

Подсказки команд расположены в нижней левой части интерфейса.
